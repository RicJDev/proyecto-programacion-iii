## Especificaciones Visuales y Tema

Para mantener la seriedad e identidad institucional requerida en un proyecto de carácter público/gubernamental:

- **Estética Plana y Seria:** Diseño **100% sin bordes redondeados (`rounded-none`)**, con líneas rectas, esquinas bien definidas y paneles limpios.
- **Tema Dinámico Vía CSS:** Paleta de colores centralizada en variables CSS (`globals.css`) mapeadas con Tailwind CSS para permitir personalización rápida del tema institucional.
- **Enfoque Componentizado:** Construido mediante un módulo interno de componentes UI atómicos reutilizables (`/components/ui`): `Button`, `Card`, `Table`, `Input`, `Badge`, `Modal`, `StatCard`, etc.
